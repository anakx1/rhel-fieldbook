Linux identifies accounts by UID and groups by GID. Names are a convenience for humans. The kernel checks numbers; the name service maps names to numbers.

RangeTypical use
0root
1–999System accounts used by services
1000+Regular interactive users (default on RHEL)

The local account database is /etc/passwd, readable by everyone. Each line has seven colon-separated fields:

passwd format
name:password-placeholder:UID:GID:GECOS:home:login-shell

On a modern RHEL system, the password field contains x and the real hash lives in /etc/shadow, which only root can read. Never copy /etc/shadow into a report. Use getent passwd student and getent group wheel to query identity through the configured name service, which may include more than local files.
