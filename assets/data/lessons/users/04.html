Accounts accumulate. Service accounts, contractors, test users, and forgotten demos all become attack surface. Build a review habit.

  • Password aging — chage -l user shows last change, expiry, and warning periods. chage -M 90 user sets a maximum age.
  • Expiry — chage -E 2026-12-31 user disables an account on a date without deleting it.
  • No login shell — service accounts should use /sbin/nologin unless they truly need interactive access.
  • Locked, not deleted — for a departure or investigation, lock first and preserve evidence; delete after retention requirements are clear.
  • Review — list UID 0 accounts, accounts with empty passwords, and members of privileged groups.
terminal · hygiene checks
awk -F: '$3 == 0 { print $1 }' /etc/passwd
sudo awk -F: '($2 == "" ) { print $1 }' /etc/shadow
getent group wheel

The first command finds every UID 0 account. There should be exactly one: root. A second UID 0 account is a backdoor until proven otherwise.
