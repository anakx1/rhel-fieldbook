Use useradd to create, passwd to set credentials, and usermod to change account attributes.

terminal · create a user
sudo useradd -m -s /bin/bash analyst
sudo passwd analyst
id analyst

-m creates the home directory from /etc/skel. -s sets the login shell. Without -m, a home directory may not be created — a classic source of "my shell config is missing" confusion. On RHEL, useradd also consults /etc/login.defs and /etc/default/useradd for defaults.

Groups come in two flavors. A user's primary group is recorded in /etc/passwd and owns new files by default. Supplementary groups add access without changing the primary group. Use -aG to append; omitting -a replaces the entire supplementary list.

terminal · groups and membership
sudo groupadd engineering
sudo usermod -aG engineering analyst
groups analyst
id analyst
-a is not optional

usermod -G wheel analyst removes every supplementary group the user had. Always think -aG when adding a group.

Lock or remove accounts deliberately. usermod -L prefixes the password hash to lock it; passwd -l does similar. userdel -r removes the home directory and mail spool, which is destructive and may not be appropriate when audit or data retention applies.
