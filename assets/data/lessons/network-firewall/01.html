On RHEL, NetworkManager owns network configuration. A device is hardware or a virtual interface. A connection is a saved profile that can be activated on a device. Multiple profiles can exist for one device; exactly one is normally active at a time.

terminal · read the state
nmcli device status
nmcli connection show
nmcli connection show "Wired connection 1"
ip -brief address
ip route

Do not judge a host by one command. nmcli describes intent and profile state; ip describes the kernel's current addressing and routes. The two should agree. If they do not, the active profile may not be the one you think.

Name the profile

Stable connection names make automation readable. A name like ens3-static is more useful than an autogenerated “Wired connection 1” when you are debugging at 02:00.
