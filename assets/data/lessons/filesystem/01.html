RHEL uses a single-rooted filesystem. There are no drive letters. Every file and directory lives somewhere beneath /, including removable media and network shares, which are attached to a directory called a mount point.

The shell is always sitting in a current working directory. pwd prints it. cd changes it. ls lists what is there. These three commands are the floor plan of everything else.

PathMeaning
/The root of the entire tree.
.The current directory.
..The parent directory.
~The current user's home directory.
~studentThe home directory of user student.
-The previous working directory, for cd -.

An absolute path starts with / and means the same thing from anywhere: /var/log/messages. A relative path is interpreted from where you are now: logs/messages only works if you are already in /var. When a script must be unambiguous, prefer absolute paths and quote them.
