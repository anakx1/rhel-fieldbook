The Filesystem Hierarchy Standard (FHS) is the shared map. You do not need to memorize every directory, but you do need to know where configuration, state, and user data belong.

DirectoryWhat lives thereWhy you care
/etcHost-specific configurationMost service configuration and identity files.
/varVariable data: logs, spool, caches, databasesThe first place to check when a disk fills.
/homeRegular user home directoriesUser data and personal shell configuration.
/rootRoot's home directoryNot the same as /.
/usrInstalled software, libraries, documentationRead-only operating system content.
/optOptional third-party application treesVendor software that brings its own layout.
/tmpTemporary filesOften cleared on reboot; never store important data.
/bootKernel and bootloader filesCritical to boot; treat with respect.
/devDevice nodesDisks, terminals, and pseudo-devices.
/proc, /sysKernel and hardware interfacesLive, virtual views — not ordinary files.
/mnt, /mediaTemporary and removable mount pointsConventional places to attach filesystems.
/srvData served by the systemOptional but conventional for service content.

On modern RHEL, /bin, /sbin, and /lib are symbolic links into /usr. This is the usrmerge layout. It is why /bin/bash and /usr/bin/bash resolve to the same program.
