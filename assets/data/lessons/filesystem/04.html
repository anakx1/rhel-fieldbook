ls is simple until you need to see hidden files, permissions, or sort order. The useful combinations:

CommandWhat it shows
ls -lLong format: type, permissions, links, owner, group, size, timestamp, name.
ls -aInclude dotfiles such as .bashrc and .ssh.
ls -lhHuman-readable sizes.
ls -ltNewest first — excellent for "what just changed?"
ls -ltrOldest first, with the newest at the bottom.
ls -ld /var/logInformation about the directory itself, not its contents.

The -d flag catches people constantly. ls -l /var/log lists the contents of the directory. ls -ld /var/log lists the directory entry itself, which is what you need when checking ownership or permissions on the directory.

Wildcards are expanded by the shell before the command runs. ls /etc/*.conf becomes a list of matching paths. If nothing matches, the literal pattern may be passed through, which is why careful scripts test with compgen or find instead of assuming a glob matched.
