tar is the standard way to bundle a directory tree. Compression is layered on top with gzip, xz, or zstd.

terminal · create, inspect, extract
tar -czf ~/lab/notes-backup.tar.gz -C ~/lab notes
tar -tzf ~/lab/notes-backup.tar.gz
mkdir -p ~/lab/restore
tar -xzf ~/lab/notes-backup.tar.gz -C ~/lab/restore

Read the flags as a sentence: c create, x extract, t list, z gzip, f file. -C changes directory for the operation, so the archive contains notes/ rather than an absolute path. This makes archives portable and prevents extraction from scattering files across the filesystem.

Always list an archive before extracting it, especially if it came from somewhere else. A malicious archive can contain absolute paths or .. traversal. tar -tzf is a cheap inspection step.

Backups are not archives

An archive is a bundle. A backup is a restore plan with retention, verification, and off-host storage. We will build the real thing in later levels.
