Wildcards expand in the shell before the command runs. They match filenames in the current directory, not file contents.

PatternMatches
*Any number of characters, including none.
?Exactly one character.
[abc]One character from the set.
[0-9]One digit.
{notes,logs}Brace expansion produces two separate arguments.
file{1..5}.txtfile1.txt through file5.txt.

Brace expansion happens before globbing and works even when files do not exist yet:

terminal · dry-run expansion
echo ~/lab/{notes,logs}
touch ~/lab/notes/day{1..3}.txt
ls ~/lab/notes

Use echo first when you are unsure. It shows what the shell would expand without running the real command. Hidden files require an explicit dot: * does not match .bashrc, while .* does — and it also matches . and .., which is why recursive deletions with .* are dangerous.
