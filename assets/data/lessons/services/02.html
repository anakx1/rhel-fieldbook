systemctl is the control interface. Use sudo for changes.

CommandEffect
systemctl start sshdStart now, do not change boot behavior.
systemctl enable --now sshdEnable at boot and start now.
systemctl restart sshdStop then start. Disrupts active connections.
systemctl reload sshdAsk the service to reload config if supported. Less disruptive.
systemctl disable sshdRemove boot activation. Does not stop the current process.
systemctl mask sshdPrevent any start, even by dependency. Stronger than disable.
systemctl unmask sshdRemove the mask.

After editing a unit file, run sudo systemctl daemon-reload. systemd caches unit definitions; without the reload, your changes may not be seen. After changing the unit's configuration file, reload or restart the service itself — those are different layers.

Restarting SSH is risky

If you are connected over SSH, restarting sshd can drop your session. On modern OpenSSH, existing sessions often survive, but do not bet your only access on it. Keep a console path open.
