A target is a boot milestone. The default on a server is usually multi-user.target; a graphical desktop uses graphical.target. Targets replace the old runlevel model but are not just renamed runlevels.

terminal · inspect boot state
systemctl get-default
systemctl list-units --type=target
systemctl --failed
systemctl list-units --type=service --state=running

systemctl --failed is one of the highest-value commands on a new system. It shows units that tried and failed, even if the rest of the boot succeeded. Investigate with systemctl status and journalctl -u.

To change the default target:

terminal · change default boot target
sudo systemctl set-default multi-user.target

Do not use systemctl isolate casually on a remote production host. Isolating a target stops units that are not part of the new target, which can terminate your access. In later levels you will practice recovery in a lab with console access.
