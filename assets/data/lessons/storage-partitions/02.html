Create a partition table with parted, then make the filesystem, mount it, and persist the mount. The exact device name is less important than the sequence and the verification after each step.

terminal · partition, format, mount
sudo parted -s /dev/sdb mklabel gpt mkpart primary xfs 0% 100%
sudo partprobe /dev/sdb
lsblk -f /dev/sdb
sudo mkfs.xfs /dev/sdb1
sudo blkid /dev/sdb1
sudo mkdir -p /data2
sudo mount UUID="REPLACE-WITH-UUID" /data2
findmnt /data2

For a permanent mount, copy the UUID into /etc/fstab:

/etc/fstab · six fields
UUID=8f3c1e2a-...  /data2  xfs  defaults  0 0

The fields are device, mount point, type, options, dump flag, and fsck pass. XFS normally uses 0 for the fsck pass because it relies on journal recovery and online repair rather than a traditional boot-time full check. Run sudo mount -a after editing; a silent success is the minimum proof that the entry parses and the UUID exists.

A bad fstab can cost you a boot

Always validate with mount -a and keep console or recovery access. If an entry is wrong, systemd can drop the machine into emergency mode waiting for a mount that will never arrive.
