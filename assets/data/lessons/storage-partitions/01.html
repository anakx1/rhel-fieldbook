Storage is easier when you keep three questions separate. Which block device exists? What filesystem is written on it? Where is that filesystem mounted? A partition is only a boundary; it is not a filesystem, and it is not usable by path until it is mounted.

terminal · read all three layers
lsblk -f
blkid
findmnt
df -hT

lsblk -f is the fastest overview: device tree, filesystem type, label, UUID, and mount point. findmnt shows the mount tree and options. df reports capacity, while du reports consumption inside a directory. They answer different questions and should disagree in healthy ways.

Read before you write

Before formatting or partitioning, prove which device you are touching. A typo in a device name is not a recoverable interface; it is a data-loss event.
