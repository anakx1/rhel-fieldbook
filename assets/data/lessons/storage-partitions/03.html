Swap gives the kernel a place to move anonymous memory pages when pressure rises. It is not a substitute for enough RAM, but it is a safety margin and a prerequisite for hibernation on systems that support it.

terminal · activate swap
sudo mkswap /dev/sdc
sudo swapon /dev/sdc
swapon --show
free -h

To persist a swap partition, add an fstab entry with swap as the type and sw as the options. A swap file is also valid, but it must live on a filesystem that supports it and must not be sparse. On RHEL, XFS supports swap files; create the file with dd or fallocate, chmod 600, mkswap, then swapon.

/etc/fstab · swap
UUID=...  none  swap  defaults  0 0

RHEL 9 and RHEL 10 both use the same fstab and swap model. XFS still cannot shrink, so capacity planning is one-way. RHEL 10's newer storage stack does not change that constraint; it only gives you better tooling around it.
