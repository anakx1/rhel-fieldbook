Ownership has two parts: user and group. chown changes both. Only root can give files to another user; a regular user may change group only to a group they belong to.

terminal · ownership
sudo chown analyst:engineering report.txt
sudo chown -R analyst:engineering ~analyst/lab
ls -l report.txt

New files get a default mode modified by the umask. The base is 666 for files and 777 for directories; the umask is subtracted bitwise (not arithmetic subtraction). A umask of 022 produces 644 for files and 755 for directories.

terminal · inspect and set umask
umask
umask 027
touch /tmp/umask-demo
ls -l /tmp/umask-demo

A umask of 027 yields 640 files and 750 directories: owner full, group read, others none. Set it in ~/.bashrc for a user or /etc/profile.d/ for a system-wide policy. Remember that umask only affects newly created objects, not existing ones.
