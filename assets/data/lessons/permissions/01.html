A long listing starts with a ten-character mode string. The first character is the file type; the next nine are three triads of permissions.

terminal · read a long listing
ls -l /etc/passwd /etc/shadow /var/log
-rw-r--r--. 1 root root 2841 Nov 12 10:14 /etc/passwd
----------. 1 root root 1842 Nov 12 10:14 /etc/shadow
drwxr-xr-x. 8 root root 4096 Nov 12 09:02 /var/log

Break -rw-r--r-- into: type - (regular file), owner rw-, group r--, other r--. The trailing dot indicates an SELinux security context is present; it is not a permission.

SymbolOn a fileOn a directory
r (4)Read contents.List names in the directory.
w (2)Modify contents.Create, rename, or delete entries.
x (1)Execute the file.Enter the directory and access known paths inside it.

The directory execute bit is the one people miss. Without x, you cannot traverse a directory even if you can read its names. Without r, you can still open a file if you know its exact path and have x.
