There are two ways to set a mode, and both are worth knowing. Octal is compact and precise. Symbolic is readable and good for targeted changes.

OctalSymbolicMeaning
640u=rw,g=r,o=Owner read/write, group read, others none.
750u=rwx,g=rx,o=Owner full, group read/execute, others none.
755u=rwx,go=rxCommon for executables and public directories.
644u=rw,go=rCommon for regular files.
terminal · chmod patterns
chmod 640 report.txt
chmod u+x deploy.sh
chmod g-w,o= report.txt
chmod -R 750 ~/lab/fieldbook

The -R flag is powerful and blunt. Recursively applying chmod 755 to a tree can make private files world-readable and remove execute bits from directories that need them. Preview with find first, then apply deliberately.

Do not chmod 777

It does not "fix permissions." It grants every local account write access and hides the real ownership or group problem. Fix the group, use an ACL, or set the correct mode.
