RPM is the package format and the low-level database. DNF is the dependency resolver and repository client that drives RPM. Think of RPM as the container and DNF as the logistics system.

TaskToolExample
Install from a repositorydnfdnf install httpd
Search available packagesdnfdnf search web server
Show package detailsdnfdnf info httpd
List installed packagesrpmrpm -qa
Find the owner of a filerpmrpm -qf /usr/sbin/httpd
List files in a packagerpm / dnfrpm -ql httpd

Packages are cryptographically signed. DNF verifies repository metadata and package signatures by default; do not disable GPG checking to make an error disappear. If a third-party repository has a bad key, fix the trust relationship or do not use the repository.

On a subscribed RHEL system, subscription-manager attaches entitlements and configures the appropriate repositories. Cloud and developer images may already be registered. Verify with:

terminal · repository state
sudo subscription-manager status
dnf repolist
ls /etc/yum.repos.d/
