Good package hygiene starts with a query. Find the exact name, confirm the source repository, and read what the package provides before changing the system.

terminal · package reconnaissance
dnf search httpd
dnf info httpd
dnf provides /usr/sbin/httpd
dnf repoquery -l httpd

dnf info shows version, release, architecture, repository, size, license, and a summary. The repository name is important: a package from an untrusted third-party repo is a different risk decision from one in the base RHEL repositories.

For installed packages, RPM answers precise questions:

terminal · installed package queries
rpm -qa | grep httpd
rpm -qi httpd
rpm -ql httpd | head
rpm -qf /etc/httpd/conf/httpd.conf
rpm -V httpd

rpm -V verifies file metadata against the package database. It can reveal modified permissions, missing files, or changed checksums. Configuration files often show as modified — that is expected. Unexplained changes in binaries are not.
