Some software is best installed as a group of packages. RHEL provides package groups for common roles:

terminal · package groups
dnf group list
sudo dnf group install "Development Tools"
dnf group info "Development Tools"

RHEL 9 also exposes module streams for selected application versions, such as alternative language runtimes. Check what is available before assuming a version:

terminal · module streams
dnf module list
dnf module info nodejs

Streams are being reworked in RHEL 10 as application streams and newer DNF behavior. Treat version-specific module commands as something to verify on the system in front of you, not something to paste blindly from an old blog post.

Finally, verify the baseline. rpm -Va checks every installed package and can take time; it is a useful audit step on a quiet system. dnf check-update tells you what is pending. dnf history tells you what happened.
