systemd is the first userspace process and the manager of boot. Firmware hands control to the bootloader, the kernel mounts the initial filesystem and starts PID 1, and PID 1 brings units up until it reaches the default target.

terminal · inspect the destination
systemctl get-default
systemctl list-dependencies multi-user.target --reverse
systemctl list-units --type=target

multi-user.target is the normal server target. A graphical installation may default to graphical.target, which pulls in multi-user first. Use systemctl set-default when changing the boot destination, and verify it before rebooting.
