A typical RHEL prompt looks like this:

prompt
[student@rhel-lab ~]$

Read it left to right. student is the current user. rhel-lab is the hostname. ~ is the current working directory, and ~ is shorthand for the user's home directory. The final character is the privilege signal: $ means a regular user; # means root.

The prompt is configured in the shell's startup files, usually ~/.bashrc and /etc/bashrc. You can change its appearance, but first learn to read it. A surprising number of "permission denied" moments are really "I thought I was root and I was not."

Root changes everything

When the prompt ends in #, there is no safety net on commands like rm, dd, or chmod. Use sudo for one command at a time instead of living in a root shell.
