Most commands follow a simple grammar: command [options] [arguments].

PartExampleMeaning
CommandlsThe program to run. Case-sensitive.
Short option-lOne behavior switch. Short flags can often be combined: -lah.
Long option--human-readableA readable version of the same idea. Usually self-documenting.
Argument/var/logThe object to act on: a path, a user, a package, a service.

Whitespace separates the parts. That means ls -l /var/log is three tokens, while ls -l/var/log is not what you meant. Quote arguments that contain spaces: mkdir "incident notes".

Some commands are shell builtins — they run inside Bash rather than as separate programs. cd, pwd, echo, and type are common examples. type cd will tell you that cd is a shell builtin; type ls usually reveals an alias or an external binary.

Exit status is the quiet language of the shell. A command returns 0 for success and a non-zero value for failure. The special variable $? holds the last result:

terminal · exit status
ls /etc >/dev/null
echo $?

This matters immediately: shell scripts and automation make decisions by checking exit status, not by reading English output.
