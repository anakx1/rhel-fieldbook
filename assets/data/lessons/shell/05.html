Most RHEL systems you administer will not have a monitor. You will reach them over SSH (Secure Shell), usually on TCP port 22.

terminal · connect to a host
ssh student@server.example.com

The first connection asks you to verify the server's host key fingerprint. In a managed environment, compare it with the value published by your team. Accepting an unknown key blindly is a security decision, not a formality.

Once connected, your local keyboard drives a shell on the remote machine. Everything you type runs there, not on your laptop. exit or logout ends the session. If a session freezes, press Enter, then ~. (tilde followed by a period) at the start of a line to terminate the SSH client.

Know where you are

Before running a destructive command over SSH, run hostname and pwd. Muscle memory from one host becomes a production incident on another.
