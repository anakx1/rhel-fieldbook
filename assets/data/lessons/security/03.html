SSH is the front door. A small configuration change has outsized impact, so validate before restarting and keep a console path.

/etc/ssh/sshd_config.d/10-baseline.conf
PermitRootLogin no
PasswordAuthentication no
PubkeyAuthentication yes
MaxAuthTries 3
X11Forwarding no

Disabling password authentication requires working key-based access first. Test with a second session before closing your current one. Validate the syntax with sshd -t, then reload:

terminal · validate SSH config
sudo sshd -t
sudo systemctl reload sshd
ssh -o BatchMode=yes student@localhost true

On RHEL 9+, drop-in files under /etc/ssh/sshd_config.d/ are included by the main configuration. Use them for local policy instead of editing the vendor file, which makes upgrades and audits easier.

Keep the firewall enabled and expose only required services. Verify listening sockets, then confirm the zone:

terminal · expose only what is needed
sudo ss -tulpn
sudo firewall-cmd --list-all
sudo firewall-cmd --permanent --add-service=https
sudo firewall-cmd --reload

Patch discipline is part of the baseline. Subscribe, test, and update deliberately. A server that has not received security updates in a year is not "stable"; it is unmaintained.
