A report is evidence with a scope. Name the source, the filter, and the time window. Save the intermediate command if the report will be repeated.

wc -l /tmp/local-users.txt
cat /tmp/auth-count.txt /tmp/local-users.txt

Quote command substitutions inside double quotes. Avoid parsing human-readable output when a tool offers a machine-readable format. When you must parse logs, anchor the pattern to the fields you actually trust and test it against a known line first.

-i is a real edit

sed -i changes the file immediately. Back it up or write to a new file first, especially when the source is a configuration file that a service depends on.

RHEL 9 vs RHEL 10

The GNU tools in this lesson are compatible across both releases. Portable options are the safer choice when the same script may run on RHEL 9 and 10; version-specific extensions belong behind a capability check.
