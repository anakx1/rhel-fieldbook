grep answers "which lines match?" sed answers "how do I change a stream?" awk answers "how do I select and format fields?" They compose because each reads standard input and writes standard output.

terminal · search and transform
sudo grep -R "Failed password" /var/log/secure
grep -nE "error|failed" /var/log/messages
sed -n "1,5p" /var/log/secure
sudo sed "s/sshd/[auth]/g" /var/log/secure | tee /tmp/auth-report.txt
awk -F: "$3 >= 1000 { print $1, $3 }" /etc/passwd

In a regular expression, a dot matches any character and a bracket expression is a character class. When you want a literal string, grep -F is faster and less surprising. Always quote patterns in the shell; otherwise the shell may expand wildcards before grep sees them.
