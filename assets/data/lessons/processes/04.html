CPU and memory questions are usually about trends, not a single snapshot. top shows live processes sorted by CPU; press M to sort by memory, P by CPU, and q to quit. free -h shows memory and swap; vmstat 1 shows runnable processes, blocked processes, swap activity, and I/O over time.

systemd-cgtop

systemd-cgtop groups resource use by control group, which is often more useful than a flat process list. A service is a cgroup; its memory and CPU are managed as a unit. systemctl status service also shows the service's main PID and recent log lines.

Do not confuse load average with CPU percentage. Load counts runnable and uninterruptible processes. A load of 8 on an 8-core system can be saturated; a load of 8 on a 2-core system is heavily oversubscribed. On Linux, high load can also mean processes stuck in D state waiting for disk.
