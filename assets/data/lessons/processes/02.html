Signals are asynchronous notifications to a process. The important ones:

SignalNumberMeaning
SIGTERM15Polite request to terminate. The default for kill.
SIGINT2Interrupt from Ctrl+C.
SIGHUP1Hangup; often used to ask a daemon to reload configuration.
SIGKILL9Immediate, unblockable termination. No cleanup.
SIGSTOP19Pause a process. Cannot be caught or ignored.
terminal · terminate with escalating force
kill -TERM 4242
kill 4242
kill -9 4242
pkill -TERM -u analyst sleep

Always try SIGTERM first. It gives the process a chance to flush buffers, close files, and release locks. SIGKILL is for a process that is genuinely stuck or ignoring termination — it can leave corrupted state or stale lock files. Killing a database with -9 is not a normal maintenance action.

Use pkill carefully: it matches broadly. pkill -u analyst sleep is narrower than pkill sleep. Run pgrep -a with the same pattern first to see exactly what would be targeted.
