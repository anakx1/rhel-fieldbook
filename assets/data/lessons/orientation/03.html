Before changing anything, establish the facts. Three files and one command tell you most of what you need to know about the platform.

terminal · identify the release
cat /etc/redhat-release
cat /etc/os-release
uname -r
hostnamectl

/etc/redhat-release is the short human-readable release string. /etc/os-release is the structured, script-friendly version used by tools across distributions. uname -r gives the running kernel; hostnamectl connects the hostname, operating system, kernel, architecture, and virtualization context in one view.

You will also use dnf constantly. Check which generation you have before relying on a manual page from the internet:

terminal · package manager generation
dnf --version

On RHEL 9 this reports DNF 4; on RHEL 10 it reports DNF5. Most everyday subcommands — install, remove, search, info, repoquery — remain familiar, but output and some flags are not identical.

A useful habit

Write down the release, kernel, and architecture before you open a support case. "It's broken" becomes actionable when you can say exactly which system is broken.
