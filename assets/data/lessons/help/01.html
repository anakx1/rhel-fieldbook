RHEL ships with its own documentation, and it works when the network does not. The primary tool is man. Manual pages are divided into numbered sections, and the number matters:

SectionContentsExample
1User commandsman 1 passwd
5File formats and configurationman 5 passwd
8System administration commandsman 8 useradd

man passwd gives you the command. man 5 passwd gives you the file format. On a system with both, the command page usually wins by default — so specify the section when you need the file layout.

Inside a manual page, use Space to page down, b to go back, /pattern to search forward, n for the next match, and q to quit. The pager is usually less; the commands are coming in the next lesson.
