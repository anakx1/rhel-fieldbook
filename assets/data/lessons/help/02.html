Most pages share a structure. You do not need to read every line; you need to know where the answer lives.

  • NAME — the command and a one-line purpose. Start here.
  • SYNOPSIS — the grammar. Brackets mean optional, ellipses mean repeatable, and a vertical bar means "or".
  • DESCRIPTION — what it does and how it thinks.
  • OPTIONS — flags, often the longest section. Search it with /.
  • FILES — configuration files that affect behavior.
  • EXAMPLES — the fastest way to understand intent, though not every page has one.
  • SEE ALSO — related pages and the next rabbit hole.

Consider this synopsis shape: cp [OPTION]... SOURCE... DEST. The command is cp, options are optional but repeatable, one or more sources are required, and a destination is required. That single line tells you cp file1 file2 dir/ is valid.

Search before you scroll

Inside man, type /-p to jump to the option you need. This is much faster than reading 400 lines of flags.
