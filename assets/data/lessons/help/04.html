You know what you want to do, but not which command does it. Search the manual index:

terminal · search the manual
man -k password
apropos password
whatis passwd

man -k and apropos search short descriptions and print matching pages. whatis prints the one-line description for a specific page. If the index is missing, rebuild it with sudo mandb.

When a command exists but you do not know where it came from, ask the package manager or RPM database:

terminal · trace a command to its package
command -v sshd
rpm -qf "$(command -v sshd)"
dnf provides '*/sshd'

command -v prints the path the shell would execute. rpm -qf asks which installed package owns that file. dnf provides finds available packages that supply a file or capability — useful when the command is not installed yet.

Aliases are not binaries

If command -v prints something like alias ls='ls --color=auto', the command is being intercepted by your shell. Use type -a ls to see all resolutions, including the real executable.
