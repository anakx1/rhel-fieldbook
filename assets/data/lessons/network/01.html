When "the network is down," establish four facts before changing anything: the interface, the address, the route, and the name resolution. Most problems live in one of those layers.

terminal · interfaces and addresses
ip addr
ip route
nmcli device status
nmcli connection show

ip addr shows interfaces, link state, MAC addresses, and IPv4/IPv6 addresses. ip route shows the routing table; the line marked default is the gateway used for off-subnet traffic. If the default route is missing, local communication may work while the internet does not.

On RHEL, NetworkManager owns network configuration. nmcli is the supported command-line interface. A device is the hardware or virtual interface; a connection is a profile applied to it. A device can have multiple profiles, but only one active connection at a time.

Files vs profiles

Do not hand-edit /etc/sysconfig/network-scripts/ifcfg-* on RHEL 9+ unless you have a specific legacy reason. Use nmcli so NetworkManager remains the source of truth.
