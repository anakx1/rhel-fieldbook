Changing networking over SSH can cut your own connection. In a lab, use the console. The pattern is: inspect, modify, bring up, verify.

terminal · static IPv4 profile
nmcli connection show "Wired connection 1"
sudo nmcli connection modify "Wired connection 1"   ipv4.method manual   ipv4.addresses 192.0.2.50/24   ipv4.gateway 192.0.2.1   ipv4.dns 192.0.2.53
sudo nmcli connection up "Wired connection 1"
ip addr show

For DHCP, set ipv4.method auto and clear the manual addresses. nmcli connection modify changes the stored profile; connection up applies it. You can also use nmcli device reapply for some changes without a full reconnect, but a lab is the place to learn the difference.

Hostname identity is separate from IP addressing. Use hostnamectl hostname rhel01.example.com to set the static hostname, and ensure DNS or /etc/hosts can resolve it.
