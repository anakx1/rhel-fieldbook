LVM inserts a flexible allocation layer between hardware and filesystems. You can add a disk to a pool, carve a new volume, or extend an existing one without repartitioning the physical device.

terminal · inspect the stack
lsblk
sudo pvs
sudo vgs
sudo lvs

Read those commands bottom-up: PVs are the raw devices, the VG is the pool, and LVs are the block devices you format and mount. The filesystem is the top layer.
