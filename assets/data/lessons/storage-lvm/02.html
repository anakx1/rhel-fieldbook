Create the stack in order. Every command should be followed by an inspection command, because LVM is stateful and a typo can attach the wrong device.

terminal · create PV, VG, LV
sudo pvcreate /dev/sdb
sudo vgcreate vgdata /dev/sdb
sudo lvcreate -n lvapp -L 5G vgdata
sudo lvs
sudo mkfs.xfs /dev/vgdata/lvapp
sudo mkdir -p /app
sudo mount /dev/vgdata/lvapp /app
findmnt /app

The device path /dev/vgdata/lvapp is a convenient symlink to the actual device-mapper node under /dev/mapper. For fstab, a UUID is still the most stable identifier. Use blkid /dev/vgdata/lvapp to read it.

Never pvcreate a disk you need

pvcreate writes LVM metadata. Confirm the device with lsblk first and remember that a cloud volume can be attached with a different name on another host.
