On RHEL 9, AppStream modules let one repository expose multiple version streams. You enable a stream before installing the package.

RHEL 9 · module stream workflow
dnf module list php
sudo dnf module enable php:8.2
sudo dnf module install php:8.2/default
dnf module list --installed

RHEL 10 ships DNF5. Everyday install and remove work, but module handling and configuration commands are not identical to DNF 4. Check dnf --version first, then use the release's own documentation. Do not paste a DNF 4 config-manager command into RHEL 10 and assume it behaves the same.
