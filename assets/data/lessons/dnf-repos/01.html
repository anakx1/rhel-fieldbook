A repository is a signed statement that packages came from a source you trust. Enable too many and you lose provenance; enable the wrong one and you install a package that looks correct but is unsupported.

/etc/yum.repos.d/fieldbook.repo
[fieldbook]
name=Fieldbook local packages
baseurl=https://repo.example.com/rhel/9/$basearch/
enabled=1
gpgcheck=1
gpgkey=https://repo.example.com/RPM-GPG-KEY-fieldbook

gpgcheck=1 is the default expectation. If a repository cannot provide a key, treat that as a design problem, not an inconvenience to bypass. Use dnf repolist -v and dnf info to verify where a package resolves.

Do not disable GPG checking to make an error disappear

A signature failure means the package or metadata is not what the repository promised. Fix trust, not the check.
