grep finds lines. Learn four flags and you can answer most log questions:

terminal · grep patterns
grep -i "failed" /var/log/secure
grep -n "error" /var/log/messages
grep -v "^#" /etc/ssh/sshd_config
grep -r "Listen" /etc/httpd/

-i ignores case, -n prints line numbers, -v inverts the match, and -r searches recursively. Add -E for extended regular expressions. Always quote patterns that contain spaces or shell metacharacters.

cut extracts columns. sort orders lines. uniq collapses adjacent duplicates, which is why it is almost always paired with sort. wc counts lines, words, or bytes.

terminal · summarize users by shell
cut -d: -f7 /etc/passwd | sort | uniq -c | sort -nr

Read that pipeline left to right: split each passwd line on colons, take the seventh field (the login shell), sort identical values together, count adjacent duplicates, then sort by count descending. This is the pattern behind a huge amount of operational reporting.

awk is the next step when column logic needs conditions or arithmetic. For now, recognize it:

terminal · a first awk
awk -F: '$3 >= 1000 { print $1, $3, $7 }' /etc/passwd

That prints local regular users: username, UID, and shell. Do not worry about mastering awk yet. The point is that text tools compose.
