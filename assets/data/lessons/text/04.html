When something fails, resist the urge to open a giant file and scroll. Narrow the question:

  1. When did it fail? Use journalctl --since or filter timestamps.
  2. Which unit or service is involved? Filter by unit or process.
  3. What changed just before? Look at the last successful event and the first error.
  4. What is the exact error? Copy the first meaningful line, not the last cascading symptom.
terminal · narrow the window
journalctl -u sshd --since "1 hour ago"
journalctl -p err -b
grep -i "failed|denied" /var/log/secure | tail -n 20

The backslash in failed|denied is basic regular expression alternation. With grep -E, write it as "failed|denied". Either way, quote the pattern so the shell does not interpret the pipe.

Copy the raw evidence

When escalating, include the exact command, timestamp, host, and unedited error. A screenshot cropped to one red line is not evidence.
