cat dumps a file to the terminal. It is perfect for short files and terrible for a 2 GB log. Use the right viewer:

CommandUse
cat fileSmall files, or feeding content into a pipe.
less filePaged reading with search. /pattern, n, q.
head -n 20 fileFirst 20 lines.
tail -n 20 fileLast 20 lines.
tail -f fileFollow new lines as they arrive. Ctrl+C to stop.
wc -l fileCount lines.

On RHEL, logs are increasingly in the systemd journal rather than flat files. journalctl provides its own paging and filtering. Flat files still exist — authentication often lands in /var/log/secure, and application logs may live under /var/log/<app>/.

less is worth learning properly. It does not load the entire file into memory the way an editor might, it preserves the terminal, and it lets you search without modifying anything. Use less +F file for a follow mode that behaves like tail -f.
