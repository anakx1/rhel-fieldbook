A user crontab has five schedule fields followed by the command. The fields are minute (0–59), hour (0–23), day of month (1–31), month (1–12), and day of week (0–7, where both 0 and 7 mean Sunday).

Cron runs with a minimal environment and no interactive shell profile. Use absolute paths, set any required PATH explicitly inside the crontab or wrapper, and redirect output so failures are not silently discarded. A wrapper script is easier to test than a long inline command.
