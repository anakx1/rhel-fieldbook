tar creates a stream. The archive path should be outside the directory being archived, or the archive will try to contain itself. The -C option changes directory before adding the named path, which keeps the stored names relative and predictable.

terminal · create and inspect
mkdir -p /home/student/lab/archive
tar -czf /home/student/lab/archive/fieldbook-notes.tar.gz -C /home/student/lab/fieldbook notes
tar -tzf /home/student/lab/archive/fieldbook-notes.tar.gz
ls -lh /home/student/lab/archive/fieldbook-notes.tar.gz

Inspect before restore. An archive that lists absolute paths or unexpected entries is a warning. Extract into an empty staging directory, never over the live tree, and compare before replacing anything.

terminal · restore into a clean target
mkdir -p /tmp/fieldbook-restore
tar -xzf /home/student/lab/archive/fieldbook-notes.tar.gz -C /tmp/fieldbook-restore
find /tmp/fieldbook-restore -type f
Compression is not encryption

A gzip archive is smaller, not secret. Use GPG or another encryption tool when the backup contains credentials or personal data.
