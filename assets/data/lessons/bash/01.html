A script is a text file that the shell executes. The first line, the shebang, names the interpreter. On RHEL, use the Bash that is actually installed:

healthcheck.sh
#!/bin/bash
set -euo pipefail

echo "host: $(hostname)"
echo "date: $(date -Iseconds)"
echo "user: $(whoami)"

Make it executable and run it:

terminal · run a script
chmod +x healthcheck.sh
./healthcheck.sh
bash healthcheck.sh

./ means "this directory." The current directory is not on PATH by default, which is a safety feature: a malicious file named ls in your working directory should not run just because you typed ls.

set -euo pipefail is the closest thing Bash has to a safety belt:

  • -e — exit on an unhandled command failure.
  • -u — error on an undefined variable.
  • -o pipefail — a pipeline fails if any stage fails, not just the last one.

It is not a substitute for thinking. Commands in conditions, pipelines, and subshells have edge cases. But it turns silent corruption into a visible failure.
