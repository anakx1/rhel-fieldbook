Assignment has no spaces around the equals sign. Expansion uses $. Quotes control how much the shell interprets.

variables and quoting
name="RHEL Fieldbook"
count=3
echo "$name"
echo 'single quotes keep $name literal'
echo "two plus three is $((2 + 3))"

Always quote variable expansions unless you have a specific reason not to: "$file", not $file. Unquoted expansions undergo word splitting and globbing, so a filename with a space can become two arguments and a filename with * can expand unexpectedly.

Script arguments are available as positional parameters:

arguments
#!/bin/bash
set -euo pipefail
echo "script: $0"
echo "first: ${1:-no argument}"
echo "count: $#"
for arg in "$@"; do
  echo "arg: $arg"
done

"$@" preserves each argument as a separate word. "$*" joins them into one string. The difference matters the moment a filename contains a space. Use "$@" as the default.

Command substitution captures output: today=$(date +%F). Avoid backticks in new scripts; $(...) nests cleanly and is easier to read.
